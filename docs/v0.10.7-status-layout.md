# PhotoShelf v0.10.7-ultra — нижняя панель

Пользователь сообщил, что между «Метаданные» и «Сведения» виден только хвост надписи «Выбрано: 1».

## Причина и исправление

Старый footer резервировал 360 DIP слева и 560 DIP справа при минимальной ширине всего окна 920 DIP. Горизонтальные StackPanel не ограничивали ширину своего содержимого: центральные кнопки, счётчик, переключатели и появляющиеся индикаторы не помещались. TextTrimming у отдельной надписи не исправлял переполнение её контейнера.

| До v0.10.7 | v0.10.7 |
|---|---|
| Все элементы в одной строке с фиксированными колонками | Статусы и элементы управления в отдельных строках |
| Счётчик делит тесный контейнер с галками и слайдером | Собственная колонка по содержимому; длинные имена ограничены 220 DIP |
| Появление прогресса расширяет блок за пределы колонки | Каждый индикатор имеет собственную колонку; статусам остаётся доступная ширина |
| При узком окне кнопки перекрываются | WrapPanel переносит элементы; высота панели Auto |
| Длинные статусы обрезаются без полного текста | Многоточие и подсказка основного статуса, метаданных и имени; специальные сведения мониторинга сохранены |

Изменена только компоновка XAML и номер версии. Обработчики выбора, мониторинг, SQL и протокол безопасного переноса не менялись. Новых заявлений о скорости или устойчивости файловых операций этот выпуск не делает.

## Проверка

Локальная Release-сборка и проверка структуры репозитория необходимы; WPF runtime проверяется отдельно Windows harness, который запускает существующие тесты и готовый EXE на синтетическом каталоге. Конкретные commit, run и результаты поставки сохраняются в сопровождающем `RELEASE.md` и отчётах архива.

Windows smoke проверяет запуск и работу окна; существующие тесты не дают отдельного подтверждения всей матрицы физических экранов и масштабов DPI. Личные фотографии в проверке не используются.
