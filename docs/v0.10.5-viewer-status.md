# PhotoShelf Ultra v0.10.5 — пустая плашка поверх фото

В окне просмотра пустой TextBlock статуса декодера сохранял фон и Padding, поэтому после успешного открытия фотографии снизу по центру оставался тёмный прямоугольник. Аналогичный пустой статус миниатюры мог рисовать полосу.

Общий стиль `MediaStatusText` сворачивает статус при пустом/null тексте. Он применяется к просмотру и сетке; непустые сообщения об ошибках и ограничении анимации остаются видимыми. Декодирование, оригиналы, каталог и протокол переноса не изменены.

Windows/WPF-регрессия загружает настоящий встроенный стиль, рисует синтетическое изображение и сравнивает все пиксели: пустой статус не должен менять фото; непустое сообщение должно появляться и полностью исчезать после очистки. Контроль без стиля воспроизводит прежний дефект. Тест не создаёт глобальный Application и не открывает пользовательские файлы.

Smoke опубликованного EXE дополнительно открывает настоящее окно просмотра синтетического HEIC и проверяет состояния пустой → непустой → пустой статус (`viewerStatusVerified`). Фактический результат Windows относится только к завершённому CI конкретного commit SHA; кросс-сборка на Mac не подтверждает отрисовку WPF. Отчёты и готовый ZIP публикуются артефактами этого CI.
