# Синхронизация с общим GitHub-репозиторием

Импорт локальной PhotoShelf Ultra v0.10.1 выполнен поверх main `902fbe889f9e8a9e948a0056c6822c1ee437303a` общего репозитория. История и исходный `docs/handoff-to-second-agent.md` сохранены.

Общий базовый снимок — v0.9.7. Изменения другого агента в `6e7eb83` учтены:

- подробный crash-log сохранён и расширен локальным ErrorReporter с полным стеком/вложенными исключениями;
- проблемные XAML-пути `(AsyncMediaImage.Status)` не возвращены: обычное свойство PreviewImage.Status сохраняет заметное предупреждение первого кадра без attached-property TypeConverter в разметке;
- промежуточное название v0.9.8 заменено согласованным v0.10.1 Ultra; проект и CI используют .NET 10;
- внешние WPF Content-иконки заменены встроенными ресурсами, как в локальном исправлении запуска;
- расширенный upstream .gitignore сохранён.

В Git импортированы исходники, тесты и документация. Релизы, ZIP, базы, кэши, исходные backup-архивы и результаты локальных тестов остаются вне Git. GitHub теперь источник актуальной версии; старые локальные архивы — исторические снимки.
