# PhotoShelf Ultra v0.10.2: проверки

## Изменения

- Локальная Ultra интегрирована в общий GitHub поверх `902fbe8` с сохранением истории и исправлений запуска upstream. Первый коммит импорта — `698a74f`.
- Во время сканирования заполненный вид не заменяется после каждого маленького пакета. Изменения накапливаются до границы этапа или кнопки «Обновить вид»; первый блок пустого вида появляется отдельно.
- Метаданные обновляются адресно; сохраняются существующие модели карточек, выделение и якорь прокрутки по пути фотографии. Перегруппировка заранее готовит страницу около якоря.
- Shift-диапазон разрешается по путям на согласованном чтении SQLite, чтобы фоновые вставки не подменяли выбранные файлы.
- Проверки запуска используют встроенные ресурсы и собственный временный каталог. Главному окну недостаточно просто существовать: проверяется готовность каталога, работа Dispatcher и штатное закрытие.
- Добавлены переносимый harness, Windows harness и GitHub Actions. Версия, структура, отсутствие служебных файлов и полные результаты TRX проверяются автоматически.

## Границы доказательств

- macOS кросс-сборка не запускает WPF и нативные Windows API. Явные платформенные пропуски не являются успешными тестами.
- UI smoke проверяет подготовку/отображение окна, декодирование синтетической PNG в реальном шаблоне карточки и штатное закрытие. За 6 секунд требуется не менее 20 наблюдений Dispatcher и отсутствие пауз более 2 секунд. Это грубая проверка зависания, не замер FPS и не замена ручной проверки большой библиотеки.
- Во время отложенной перегруппировки загруженные карточки остаются стабильными. Ещё не загруженные страницы читают актуальную БД; вид не держит длительный snapshot всей библиотеки. Итоговые границы групп обновляются на завершении этапа.
- Старые SQL-замеры не доказывают ускорение интерфейса относительно v0.9.7. Для такого сравнения нужны одинаковая Windows-машина, библиотека и методика.
- Файловый протокол не заменялся ради ускорения UI. Синтетические process-kill/native тесты не покрывают отключение питания, отказ носителя и все файловые системы/USB-устройства.
