# PhotoShelf Ultra v1.11 — обновления из интерфейса

Отображаемая версия — **1.11**; техническая версия сборки и подписанного канала — **1.11.0-ultra**.

## Поведение

Проверка GitHub запускается один раз после появления основного окна, без ожидания в пути загрузки каталога. Её можно отключить в настройках; ручная кнопка остаётся доступной. Сетевые ошибки проверки не показываются, дата последней успешной проверки не подменяется, отсутствие ответа не означает последнюю версию.

Предложение можно отложить на сутки или пропустить для конкретной версии. Ручная проверка обходит подавление предложения. Отдельные действия: скачать пакет; обновить и перезапустить. Ни закрытие программы, ни её новый запуск, ни восстановление сохранённой загрузки не дают согласия на установку.

## Сохранность

- Загрузка и распаковка идут в новую owned-папку, с ограничениями размера, подписью RSA-SHA256 и проверкой инвентаря файлов.
- ZIP paths, links/reparse, ADS и коллизии Windows-имён отвергаются. Неопределённые и прерванные загрузки не удаляются как кэш.
- Перед переключением Desktop завершает фактические readers/writers и сохраняет состояние. Обновление можно отложить во время подготовки.
- Helper ждёт именно прежний PID+время старта; никогда не завершает старое приложение принудительно.
- Установка создаёт новую versioned-папку; исходники медиа, каталог, журналы и предыдущие программы не перезаписываются.
- Перед публикацией pointer проверяется запуск EXE с изолированным временным каталогом. После запуска с настоящим каталогом автоматического возврата старой БД/EXE нет.
- Перенос схемы каталога в этом выпуске не меняется: подписанный канал ограничен схемой 5.
