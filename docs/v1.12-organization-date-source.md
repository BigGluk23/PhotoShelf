# v1.12: явный источник даты при раскладке

Этот срез развивает задачу #4 и не вводит новый механизм файловых операций. Drag-and-drop,
кнопка «Разложить…», предварительный план и выполнение продолжают использовать общий
`FileMoveService` с no-overwrite, связанными группами, SHA-256, durable-журналом,
recovery и undo.

## Поведение

В предварительном плане пользователь явно выбирает один из режимов:

- **Дата съёмки — без подмены**: используется только нормализованная дата съёмки из
  каталога. Время файла не маскирует отсутствие EXIF.
- **Дата съёмки, иначе дата файла**: дата файла применяется только как явно выбранный
  fallback, когда даты съёмки нет.
- **Дата файла**: структура и префикс имени строятся по времени изменения файла независимо
  от наличия даты съёмки.

Для каждой строки план показывает выбранную дату и фактический источник: «Съёмка»,
«Файл» или «Нет даты». Сводка считает источники по связанным группам, а не повторно по
каждому XMP/AAE/RAW companion. Файлы без выбранной даты попадают в отдельную видимую
папку: «Без даты съёмки», «Без даты файла» либо «Без даты съёмки и файла».

## Инварианты

- default остаётся консервативным: capture date без fallback;
- дата не читается заново синхронно из файла в WPF Dispatcher, используются уже
  индексированные поля выбранных элементов;
- один источник даты применяется ко всей подтверждённой companion-группе;
- перенос не редактирует metadata и не перекодирует медиа;
- изменение режима пересобирает только отменяемый preview в фоне и ничего не перемещает;
- выполнение возможно только после показа готового неизменяемого плана.

## Проверка

Application-тесты проверяют отсутствие неявного fallback, явный fallback на дату файла,
приоритет даты съёмки при наличии обеих дат, режим только filesystem timestamp, отдельную
папку без даты, структуру год/месяц/день и префикс имени. Полный WPF/Windows lifecycle,
комплект HEIC и publish smoke остаются обязательным CI-gate конкретного commit SHA.

Тесты используют только синтетические файлы. Process-kill не моделирует физическое
отключение питания или отказ накопителя; независимая резервная копия оригиналов остаётся
обязательной защитой от потери устройства.
