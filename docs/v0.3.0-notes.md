# PhotoShelf v0.3.0

Этот срез переводит проект от простого просмотрщика к каталогу в духе Picasa.

## Что добавлено

1. Галерея теперь группирует вывод по годам и месяцам. Пока дата берётся из файловой системы, дальше приоритет будет у DateTimeOriginal/CreateDate из метаданных.
2. SQLite-каталог инициализируется при запуске в `%AppData%\PhotoShelf\catalog-v2.sqlite`. JSON остаётся безопасным fallback-слоем на время перехода.
3. Добавлен дисковый кэш миниатюр в `%AppData%\PhotoShelf\thumb-cache`, чтобы повторное открытие больших папок меньше нагружало декодеры.
4. Схема SQLite расширена под запоминание сеансов поиска дублей, групп дублей, пользовательских решений и будущих backend-декодеров.
5. В основной схеме уже есть нормализованные EXIF/XMP/IPTC-поля, raw metadata-пары, теги, GPS, sidecar/Live Photo-модель, карантин и индексы для будущих фильтров.

## Что ещё не считается полностью готовым

- Нативные HEIC/HEIF/HDR/RAW/видео-декодеры пока не поставляются как отдельные bundled-библиотеки. Архитектурная точка входа и таблица возможностей добавлены, но сами libheif/LibRaw/FFmpeg нужно подключать отдельным следующим шагом.
- SQLite пока включён как новый каталог и схема хранения, но UI ещё использует JSON как fallback для совместимости с уже найденной библиотекой. Следующий шаг — перевести сохранение найденных файлов и хэшей дублей в SQLite полностью.
- Группировка сейчас по дате файла. После полноценного metadata-reader нужно переключить её на дату съёмки, а LastWriteTime оставить только fallback.
