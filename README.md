# PhotoShelf 0.9.7

Локальный менеджер фото и видео для Windows x64, C# / .NET 9 / WPF.

## Запуск

Распакуйте `releases/PhotoShelf-v0.9.7-win-x64.zip` целиком и запустите `PhotoShelf.exe`.
Архив содержит автономную сборку с .NET runtime. Папка `Assets` должна оставаться рядом с EXE.
Каталог и журналы находятся в `%APPDATA%\PhotoShelf`. Оригиналы не копируются при сканировании.

## Что изменено

- Состояние загружается перед открытием главного окна; восстановлены режим даты, сортировка, выбранная папка/вид, масштаб, скрытые/системные папки и раскрытые ветви.
- Каталог читается по 128 записей с ожиданием применения каждого пакета. Статистика файлов проверяется отдельно в фоне.
- Фильтрация, сортировка и подготовка строк выполняются в фоне. При новом выборе предыдущая операция отменяется. UI применяет строки порциями по 24.
- Дерево раскрывается асинхронно. Клик по папке открывает её файлы независимо от галки. Переключатель «Подпапки» задаёт глубину просмотра. Галка управляет участием в библиотеке/сканировании.
- Сохранение сериализовано и отложено; смена настроек не перезаписывает таблицу файлов. Недоступный диск больше не считается удалением файлов.
- SQL-код вынесен из Desktop в Infrastructure.Sqlite; DTO состояния — в Application.
- Ctrl/Shift-выделение, drag-and-drop в папку дерева, предварительный план, пропуск/переименование совпадений, раскладка выбранного по годам и месяцам через контекстное меню.
- Перенос и карантин выполняются в фоне через один сервис: журнал, временное сохранение источника, копирование, SHA-256, публикация без перезаписи, фиксация каталога, завершение операции.
- Поиск дублей проверяет актуальные размер/дату файла перед повторным использованием хэша. Доступны вся библиотека, текущий вид, отмеченные папки, выбранная папка и сравнение двух папок.
- GIF и animated WebP получают кадры через ImageSharp в фоне; анимация останавливается при выгрузке элемента. Для больших анимаций показывается первый кадр с видимой подписью.
- Метаданные читаются в фоне: EXIF/IPTC/XMP через ImageSharp, затем WIC как fallback. Дата файла и дата съёмки сохраняют разные значения.

## Проверка и ограничения

Сборка и кроссплатформенные тесты выполнены на macOS. Запуск Windows EXE, отзывчивость WPF, drag-and-drop, видеоплеер и визуальная корректность анимации на Windows **не проверены**. Исчезновение всех зависаний не заявляется без такого прогона. Проверки для Windows: `docs/v0.9.7-validation.md`.

Перенос доступен после первичной загрузки каталога. Раскладка использует дату съёмки, а неизвестные даты помещает в `Без даты съёмки`; если индексация ещё идёт, дождитесь её завершения для полного плана.

Автоматический откат из интерфейса пока не реализован. Журнал содержит исходный, целевой и временные пути, SHA-256 и последний этап; инструкции восстановления — в `docs/v0.9.7-validation.md`. При сбое БД возможны две сохранённые копии — это отражено в журнале.

Файлы с соседними AAE/XMP пока пропускаются при переносе: требуется операция над связанной группой. HEIC/HEIF/RAW/Live Photo остаются в доменных контрактах; встроенные декодеры этих форматов и resolver связей ещё не реализованы. Видеоплеер пока использует WPF MediaElement и доступные на Windows видеодекодеры.

## Сборка

Нужен .NET 9 SDK. `Directory.Build.props` восстановлен: в переданном v0.9.6 отсутствовали общие настройки сборки.

```powershell
dotnet build src/PhotoShelf.Desktop/PhotoShelf.Desktop.csproj -c Release
dotnet test tests/PhotoShelf.Domain.Tests/PhotoShelf.Domain.Tests.csproj -c Release
dotnet test tests/PhotoShelf.Application.Tests/PhotoShelf.Application.Tests.csproj -c Release
dotnet test tests/PhotoShelf.Infrastructure.Sqlite.Tests/PhotoShelf.Infrastructure.Sqlite.Tests.csproj -c Release
dotnet publish src/PhotoShelf.Desktop/PhotoShelf.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o artifacts/PhotoShelf-v0.9.7-win-x64
```
