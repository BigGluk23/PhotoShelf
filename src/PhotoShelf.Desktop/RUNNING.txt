PhotoShelf Ultra v0.10.3 — Windows x64

Распакуйте весь ZIP и запустите PhotoShelf.exe.
.NET runtime, иконки и изображения интерфейса включены в EXE. Папка Assets для запуска не требуется.

Настройки, каталог, диагностика и журналы: %APPDATA%\PhotoShelf
Карантин: папка Изображения\PhotoShelf_Quarantine

Ctrl/Shift — массовое выделение. Перетащите выбранное в папку дерева для плана переноса.
«Разложить выбранные по годам…» доступно в контекстном меню.
«Операции» — история, восстановление, откат, резервная копия каталога.

Сборка и переносимые тесты выполнены на macOS. Windows UI и нативные проверки требуют запуска на Windows. Сначала проверьте на копии библиотеки.
Не удаляйте журналы и временные .photoshelf-* файлы вручную.
Журнал не заменяет отдельную резервную копию оригиналов.
Подробности: README.md и docs/v0.10.3-review-fixes.md в этом архиве.

При ошибке полный журнал: %APPDATA%\PhotoShelf\diagnostics\errors
