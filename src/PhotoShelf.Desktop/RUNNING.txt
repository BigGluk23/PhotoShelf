PhotoShelf v0.9.7 — Windows x64

Распакуйте весь ZIP и запустите PhotoShelf.exe.
.NET runtime включён в автономную сборку; Assets должна находиться рядом с EXE.

Настройки, каталог и журналы: %APPDATA%\PhotoShelf
Карантин: папка Изображения\PhotoShelf_Quarantine

Ctrl/Shift — массовое выделение. Перетащите выбранное в папку дерева для плана переноса.
«Разложить выбранные по годам…» доступно через контекстное меню миниатюры.

Сборка и тесты выполнены на macOS. Работа UI на Windows требует проверки.
Подробности и ограничения: README.md и v0.9.7-validation.md из архива.
